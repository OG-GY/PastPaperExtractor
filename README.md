# PastPaperExtractor

> Extract, parse, and store university past papers from PDFs — built with Python and Streamlit.

A utility tool for students that eliminates the manual work of hunting through PDF past papers. Upload a PDF, the app parses through the content, extracts questions and relevant data, and saves everything in a structured, searchable format.

---

## What It Does

- **PDF Parsing** — Reads through university past paper PDFs and extracts text content
- **Structured Storage** — Saves extracted data in an organized, retrievable format
- **Search & Retrieve** — Find specific papers or questions without manually opening PDFs
- **Web Interface** — Clean Streamlit UI — no command line needed

---

## Tech Stack

| | |
|---|---|
| Language | Python |
| UI | Streamlit |
| PDF Parsing | PyPDF2 / pdfplumber |
| Storage | Local file system / structured output |

---

## Use Case

Built to solve a real problem for UET Lahore students — past papers are scattered across drives and WhatsApp groups as PDFs. This tool centralizes and makes them searchable in seconds.
